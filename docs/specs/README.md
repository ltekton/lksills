# Specifications

The active MVP specifications are:

- [Workarea](workareas.md) - one explicit local workarea;
- [Acquisition](acquisition.md) - one-bundle import from local/Git origins;
- [Local management](local-management.md) - existing validation and publishing.

The following documents are retained as deferred design history and are not MVP
requirements:

- [Upstream coordination](upstream-coordination.md);
- [Packaging](packaging.md);
- [Publication](publication.md).

The MVP uses the existing concrete `publish` renderer. It does not introduce the
package/catalog/publication abstractions described by the earlier design.
