# Specifications

The active specifications are:

- [Project and global scope](workareas.md);
- [Dependency resolution and installation](acquisition.md);
- [Authoring, forks, and deployment](local-management.md);
- [Update and upstream coordination](upstream-coordination.md);

Together they define a TOML manifest/lockfile package lifecycle for Agent Skills.
Internal workareas and caches are implementation details; the user-facing concepts
are package, skill, dependency, lockfile, fork, bundle, target, and scope.
